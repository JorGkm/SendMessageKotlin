# Manual de Usuario — SendMessage

> **[IA]** Guía sencilla para usar la aplicación SendMessage.

---

## ¿Qué es SendMessage?

SendMessage es una aplicación muy simple que te permite **escribir un mensaje** en una pantalla y **verlo** en la siguiente pantalla.

---

## Cómo usar la aplicación en 3 pasos

### Paso 1: Escribe tu mensaje

Al abrir la aplicación, verás una pantalla con un **cuadro de texto** grande.

👉 **Toca el cuadro de texto** y escribe el mensaje que quieras enviar.

```
┌─────────────────────────────────────┐
│  SendActivity                       │
│                                     │
│  ┌───────────────────────────────┐  │
│  │ Escribe aquí el mensaje...    │  │
│  │ ¡Hola, mundo!                 │  │  ← Escribe aquí
│  │                               │  │
│  └───────────────────────────────┘  │
│                                     │
│  ┌─────────┐                        │
│  │ Enviar  │                        │
│  └─────────┘                        │
└─────────────────────────────────────┘
```

---

### Paso 2: Pulsa el botón "Enviar"

Debajo del cuadro de texto hay un **botón morado** que dice **"Enviar"**.

👉 **Toca el botón "Enviar"** para enviar tu mensaje a la siguiente pantalla.

---

### Paso 3: Mira tu mensaje

La aplicación cambiará automáticamente a una nueva pantalla donde verás **el mensaje que escribiste** dentro de un **cuadro morado**.

```
┌─────────────────────────────────────┐
│                                     │
│           ⚠️                        │
│                                     │
│  ┌───────────────────────────────┐  │
│  │                               │  │
│  │ ¡Hola, mundo!                 │  │  ← Tu mensaje aquí
│  │                               │  │
│  └───────────────────────────────┘  │
│                                     │
└─────────────────────────────────────┘
```

---

## Resumen

| Paso | Acción |
|---|---|
| **1** | Escribe tu mensaje en el cuadro de texto |
| **2** | Pulsa el botón "Enviar" |
| **3** | Mira tu mensaje en la siguiente pantalla |

---

## Notas

- Si no escribes nada y pulsas "Enviar", la segunda pantalla aparecerá vacía.
- Para volver a la primera pantalla, usa el **botón "Atrás"** de tu teléfono.
